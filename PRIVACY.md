# Privacy Policy for Crossword Date Navigator

Last updated: October 10, 2026

## Overview
Crossword Date Navigator is an open-source browser extension designed to provide on-screen date navigation buttons on the New York Times Mini, Midi and Daily Crossword webpages.

## Data Collection
- **No Personal Data Collected**: The extension does not collect, store, transmit, or sell any personal data, browsing history, or user information.
- **No Third-Party Analytics**: The extension does not contain tracking pixels, analytics SDKs, or third-party cookies.
- **Local Operation**: All date arithmetic, DOM injection, and navigation occur entirely locally within your browser.

## Permissions Rationale
- **Content script matches (`https://www.nytimes.com/crosswords/game/mini*`, `https://www.nytimes.com/crosswords/game/midi*`, `https://www.nytimes.com/crosswords/game/daily*`)**: Required exclusively to read the current puzzle date, add navigation buttons and handle date shortcuts on these crossword pages. The extension has no access to other domains and does not run its navigation controls on other puzzle types.

## Contact
If you have any questions regarding this privacy policy, please open an issue in the project repository.
